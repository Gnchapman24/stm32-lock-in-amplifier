# STM32 Two-Channel Lock-In Amplifier & Bode Analyzer

A two-channel digital lock-in amplifier built on an STM32G474. It measures the
amplitude and phase of small signals at a chosen reference frequency, even when they
are buried in noise far larger than the signal. Its main application is a **Bode /
frequency-response analyzer**: it sweeps a sine excitation across 10 Hz – 10 kHz,
measures a circuit's input and output simultaneously, and reports gain and phase.

> **Status:** early development. Results, schematics and measured performance will be
> added as each stage is completed.

## How it works

The input `s(t) = A·sin(2π·f_ref·t + φ) + noise` is multiplied by a sine and a cosine
at `f_ref` (generated by a numerically controlled oscillator). Each product contains a
DC term proportional to the part of the signal in phase with that reference, plus a
`2·f_ref` term and frequency-shifted noise. A low-pass filter keeps only the DC terms,
giving the in-phase and quadrature components:

```
X = (A/√2)·cos φ     Y = (A/√2)·sin φ     (V RMS)
R = √(X² + Y²)       θ = atan2(Y, X)      (V RMS, rad)
```

The narrower the low-pass filter, the more noise is rejected, at the cost of a slower
response. With two channels demodulated against the same reference, the ratio
`H = (X₂ + jY₂) / (X₁ + jY₁)` gives a circuit's transfer function directly, with the
excitation's own amplitude and phase cancelling out.

## Features (planned)

- Two differential, AC-coupled input channels with simultaneous sampling
- Arbitrary reference frequency, 10 Hz – 10 kHz (32-bit NCO), sine excitation output
- Time constants 1 ms – 10 s, 6/12/18/24 dB/oct filters, optional sync filter
- Harmonic detection (k·f_ref)
- Q31 fixed-point DSP using the STM32G4 CORDIC accelerator
- Bode sweep with through-calibration; impedance measurement mode
- SCPI-style command interface; Python host for logging, sweeps and plots

## Hardware

- NUCLEO-G474RE (Cortex-M4F @ 170 MHz, dual 12-bit ADCs, DAC, CORDIC, FMAC)
- Instrumentation-amplifier front end, one per channel (breadboard, later a KiCad shield)
- Validation demo: ratiometric optical absorbance with an LED and two photodiodes

## Building

CMake + `arm-none-eabi-gcc`. Instructions will be added with the first firmware commit.
